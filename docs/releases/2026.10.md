# DDC Converters 2.0

DDC Converters 2.0 is the October 2026 release of the whole line: RVT Converter 2.0, RVT to IFC 2.0,
IFC to Excel 2.0, CAD Drawing to Excel 2.0, Data Viewer 2.0 and Excel Add-in 2.0. Each run writes a report of what
was read and what was skipped.

## Packages

| Package | Version | Reads | Writes |
|---|---|---|---|
| DDC RVT Converter | 2.0 | `.rvt`, `.rfa` saved by Autodesk® Revit® 2019–2027 | GLB, glTF, OBJ, IFC4, element table (XLSX, CSV), properties JSONL; desktop app also CSV / SQLite |
| DDC RVT to IFC | 2.0 | `.rvt`, `.rfa` | IFC4 with profiles `full`, `coordination`, `geometry` |
| DDC IFC to Excel | 2.0 | IFC2x3 / IFC4, `.ifczip` | XLSX, JSONL, SQLite |
| DDC CAD Drawing to Excel | 2.0 | `.dwg` R13–2018 | XLSX, CSV, JSONL, DXF, SVG |
| DDC Data Viewer | 2.0 | XLSX, CSV, JSONL, Parquet + GLB / DAE | XLSX, CSV |
| DDC Excel Add-in (Excel 2016+) | 2.0 | `.rvt`, `.rfa`, `.ifc`, `.ifczip`, `.dwg` through the converters above (downloaded on first use after confirmation) | Excel table, one row per element |

`*-Setup.exe` is a Windows installer; `*-portable.zip` runs from any folder without installation.
Windows 10/11 x64. Linux (x64, arm64) and macOS (arm64, x64) builds: see the Linux and macOS section below.

## Linux and macOS

Command-line converters for Linux (x64, arm64) and macOS (Apple Silicon arm64, Intel x64), and the Data Viewer
as AppImage / deb (Linux) and dmg / app (macOS). Same file formats and reports as the Windows packages.

| Package | Version | Files |
|---|---|---|
| DDC RVT Converter (command line `rvt-decode`) | 2.0.0 | `rvt-decode-2.0.0-{linux-x64,linux-arm64,macos-arm64,macos-x64}.tar.gz` |
| DDC IFC to Excel (`ifc2excel`) | 2.0.1 | `ifc2excel-2.0.1-{linux-x64,linux-arm64,macos-arm64,macos-x64}.tar.gz` |
| DDC CAD Drawing to Excel (`dwg2excel`) | 2.0.0 | `dwg2excel-2.0.0-{linux-x64,linux-arm64,macos-arm64,macos-x64}.tar.gz` |
| DDC Data Viewer | 2.0.0 | `ddc-data-viewer-2.0.0-linux-*.AppImage` / `.deb`, `ddc-data-viewer-2.0.0-macos-*.dmg` / `.app.tar.gz` |

```bash
tar xzf ifc2excel-2.0.1-linux-x64.tar.gz
./ifc2excel-2.0.1-linux-x64/ifc2excel Building.ifc --output out
./dwg2excel-2.0.0-linux-x64/dwg2excel Plan.dwg --output out
./rvt-decode-2.0.0-linux-x64/rvt-decode --help
```

- **Linux:** glibc 2.35 or newer (Ubuntu 22.04 or newer, Debian 12 or newer). The Data Viewer needs WebKitGTK 4.1
  (`libwebkit2gtk-4.1-0`).
- **macOS:** the binaries are signed ad hoc and not notarized. After unpacking, clear the download quarantine flag once:
  `xattr -dr com.apple.quarantine <unpacked folder or .app>` (for the dmg: open it, copy the app to Applications, then run
  the same command on the app).
- **Verify:** `sha256sum -c SHA256SUMS-linux-macos.txt` (macOS: `shasum -a 256 -c`). The checksum file is signed with
  keyless cosign: `cosign verify-blob --bundle SHA256SUMS-linux-macos.txt.cosign.bundle --certificate-identity-regexp
  'https://github.com/datadrivenconstruction/ddc-release-builds/' --certificate-oidc-issuer
  https://token.actions.githubusercontent.com SHA256SUMS-linux-macos.txt`.
- The packages are built by a public GitHub Actions workflow
  ([ddc-release-builds](https://github.com/datadrivenconstruction/ddc-release-builds)) and checked on the build
  machines by converting small open sample files.

## What is new

- **IFC4 export from Revit:** openings and fill relations for doors and windows, building storeys from the
  document's levels, curtain walls, stairs and railings with their parts, closed bodies, MEP systems with
  distribution ports and connections, pipe materials, common property sets for MEP elements and base quantities
  (wall gross and net side area and volume, slab area and perimeter, panel areas, member span).
- **Element ids everywhere:** every geometry node keeps the native element id, so tables and 3D join by `ElementId`.
- **DDC Data Viewer 2.0:** free table and 3D viewer with two-way linking between rows and elements; English, German
  and Russian; light and dark theme.
- **Reports for every run:** `report.json`, `summary.json`, `result.json` or `REPORT.txt` with counts.
- **Desktop apps and command line** for every converter, with exit codes and one-line JSON status for scripts.

## Command lines

```powershell
RVTconverter.exe "C:\Models\Project.rvt" -o "C:\Out\Project" --properties --ifc
runtime\python.exe sources\ifc-excel\converter.py "C:\Models\Building.ifc" --output "C:\Out\Building"
dwg2excel.exe "C:\Drawings\Plan.dwg" -o "C:\Out"
```

## Supported scope

- RVT: textures are not exported; IFC export writes tessellated IFC4.
- IFC: IFCXML is not supported.
- DWG: some object types are listed as unsupported in `report.json` instead of being exported.
- Windows 10/11 x64.

## RVT Converter and RVT to IFC 2.0.1 (2026-10-21)

- Free for non-commercial use only; commercial use requires a licence on request (EULA 1.0 is in each package).
- The IFC app is called "DDC RVT to IFC" (the program file keeps its name, `Revit to IFC.exe`). New language: Português (Brasil).
- Older Revit files such as Revit 2015 convert in the apps like they do on the command line, and a written result is no longer discarded over an opening counter.
- IFC export: stable GlobalId from the Revit UniqueId, quantities for open bodies, doors and windows.
- Plainer wording in the options, a status line that no longer shows "0%" for a single file, and a wrapped result line at 960 px.
- Command-line compatibility names `RvtExporter.exe` and `RVT2IFCconverter.exe` are included in `cli/`.
