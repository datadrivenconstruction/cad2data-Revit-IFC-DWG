# DDC Converters 2.0

DDC Converters 2.0 is the October 2026 release of the whole line: RVT Converter 2.0, RVT to IFC 2.0,
IFC to Excel 2.0, CAD Drawing to Excel 2.0, Data Viewer 2.0 and Excel Add-in 2.0. Each run writes a report of what
was read and what was skipped.

## Packages

| Package | Version | Reads | Writes |
|---|---|---|---|
| DDC RVT Converter | 2.0 | `.rvt`, `.rfa` saved by Autodesk® Revit® 2019–2027 | GLB, glTF, OBJ, IFC4, element table (XLSX, CSV), properties JSONL; desktop app also CSV / SQLite |
| DDC RVT to IFC | 2.0 | `.rvt`, `.rfa` | IFC4 with profiles `full`, `coordination`, `geometry` |
| DDC IFC to Excel | 2.0 | IFC2x3 / IFC4, `.ifczip` | XLSX, JSONL, SQLite |
| DDC CAD Drawing to Excel | 2.0 | `.dwg` R13–2018 | XLSX, CSV, JSONL, DXF, SVG |
| DDC Data Viewer | 2.0 | XLSX, CSV, JSONL, Parquet + GLB / DAE | XLSX, CSV |
| DDC Excel Add-in (Excel 2016+) | 2.0 | `.rvt`, `.rfa`, `.ifc`, `.ifczip`, `.dwg` through the converters above (downloaded on first use after confirmation) | Excel table, one row per element |

`*-Setup.exe` is a Windows installer; `*-portable.zip` runs from any folder without installation.
Windows 10/11 x64. Linux and macOS builds are coming soon.

## What is new

- **IFC4 export from Revit:** openings and fill relations for doors and windows, building storeys from the
  document's levels, curtain walls, stairs and railings with their parts, closed bodies, MEP systems with
  distribution ports and connections, pipe materials, common property sets for MEP elements and base quantities
  (wall gross and net side area and volume, slab area and perimeter, panel areas, member span).
- **Element ids everywhere:** every geometry node keeps the native element id, so tables and 3D join by `ElementId`.
- **DDC Data Viewer 2.0:** free table and 3D viewer with two-way linking between rows and elements; English, German
  and Russian; light and dark theme.
- **Reports for every run:** `report.json`, `summary.json`, `result.json` or `REPORT.txt` with counts.
- **Desktop apps and command line** for every converter, with exit codes and one-line JSON status for scripts.

## Command lines

```powershell
RVTconverter.exe "C:\Models\Project.rvt" -o "C:\Out\Project" --properties --ifc
runtime\python.exe sources\ifc-excel\converter.py "C:\Models\Building.ifc" --output "C:\Out\Building"
dwg2excel.exe "C:\Drawings\Plan.dwg" -o "C:\Out"
```

## Supported scope

- RVT: textures are not exported; IFC export writes tessellated IFC4.
- IFC: IFCXML is not supported.
- DWG: some object types are listed as unsupported in `report.json` instead of being exported.
- Windows 10/11 x64.
