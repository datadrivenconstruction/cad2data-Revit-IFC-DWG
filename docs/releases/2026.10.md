# DDC converters 2026.10 — first-party file readers

This release replaces the converter generation 18.x with new converters built on
DataDrivenConstruction's own RVT, IFC and DWG readers. No third-party CAD SDK is used.
All packages are **previews**: each run writes a report of what was read, skipped or refused.

## Packages

| Package | Version | Reads | Writes |
|---|---|---|---|
| DDC RVT Converter | 0.6.8 | `.rvt`, `.rfa` saved by Autodesk® Revit® 2019–2027 | GLB, glTF, OBJ, IFC4 (experimental), properties JSONL; desktop app also CSV / SQLite |
| DDC RVT to IFC | 0.6.8 | `.rvt`, `.rfa` | IFC4 with profiles `full`, `coordination`, `geometry` |
| DDC IFC to Excel | 0.3.1 preview | IFC2x3 / IFC4, `.ifczip` | XLSX, JSONL, SQLite |
| DDC DWG to Excel | 0.4.1 | `.dwg` R13–2018 | XLSX, CSV, JSONL, DXF, SVG |
| DDC Data Viewer | 0.1.2 | XLSX, CSV, JSONL, Parquet + GLB / DAE | XLSX, CSV |

`*-Setup.exe` is a Windows installer; `*-portable.zip` runs from any folder without installation.
The packages are not code-signed yet.

## Command lines

```powershell
RVTconverter.exe "C:\Models\Project.rvt" -o "C:\Out\Project" --properties --ifc
runtime\python.exe sources\ifc-excel\converter.py "C:\Models\Building.ifc" --output "C:\Out\Building"
dwg2excel.exe "C:\Drawings\Plan.dwg" -o "C:\Out"
```

## Changes compared with 18.x

- New executables and output layout (see README → *Command line*). The RVT command line writes
  properties as JSONL instead of XLSX and geometry as GLB instead of DAE.
- DGN conversion and PDF sheet export are discontinued in this generation.
- The n8n workflows and notebooks in the repository still target 18.x and are being ported.

## Known limitations

- RVT: geometry completeness not certified, no textures, experimental source colours, IFC4 tessellated
  and not schema-validated by the tool.
- IFC: IFCXML not supported; computed properties not qualified.
- DWG: some object types are reported as unsupported or refused instead of being exported; see `report.json`.
- Windows 10/11 x64 only.
