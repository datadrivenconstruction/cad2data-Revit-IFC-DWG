# Sample projects

This folder contains only sample files that DataDrivenConstruction may
redistribute (open IFC samples). Third-party sample models are **not**
redistributed in this repository.

To test the converters with the Autodesk® Revit® or AutoCAD® sample models,
download them directly from the vendor under the vendor's own terms, e.g. the
Revit sample files published by Autodesk ("rac_basic_sample_project",
"rst_advanced_sample_project"), and place them in this folder locally.
