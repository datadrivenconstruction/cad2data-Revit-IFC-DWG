DDC IFC to Excel - переносимая версия

Windows x64. Откройте IFC to Excel.exe, перетащите IFC/IFCZIP (или нажмите Ctrl+O),
нажмите Convert. Python и Excel отдельно устанавливать не нужно.
Папку приложения переносите целиком; исходные модели не изменяются.

Командная строка:  "IFC to Excel.exe" --help   (справка, окно не открывается)
                   "IFC to Excel.exe" model.ifc --output C:\out   (без окна)

Community - бесплатно, регистрация не нужна. Необязательная регистрация по e-mail
хранится только на этом компьютере (%APPDATA%\DataDrivenConstruction\registration.json).

Ограничения: геометрия, вычисляемые свойства и полнота исходных данных не квалифицированы.
IFCXML не поддерживается. Описание листов: README.md.
Тексты лицензий: папка licenses/.
