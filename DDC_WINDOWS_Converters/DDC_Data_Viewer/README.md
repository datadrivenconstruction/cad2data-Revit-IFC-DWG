# DDC Data Viewer 2.0 (portable, Windows x64)

Free desktop viewer for XLSX / CSV / JSONL / Parquet tables with linked GLB / DAE 3D models.
Start `DDC Data Viewer.exe`; try `samples\Sample Building.csv` with `samples\Sample Building.glb`.
Needs the Microsoft WebView2 runtime (see `WEBVIEW2.txt`). It is a desktop app, there is no CLI.
Licence: `LICENSE.txt`. Version: file name in the [Releases](https://github.com/datadrivenconstruction/cad2data-Revit-IFC-DWG/releases).
