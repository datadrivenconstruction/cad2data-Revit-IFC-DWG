DDC DWG to Excel - provenance and third-party notices

DWG decoding is done by DataDrivenConstruction's own clean-room reader
(dwg-independent). No ODA/Teigha/Open Design Alliance, Autodesk RealDWG,
LibreDWG or any other external DWG implementation, code or specification
text is used or bundled. "AutoCAD" and "DWG" are used only to describe the
file format this software reads; no affiliation with Autodesk, Inc.

The program is compiled with Nuitka (Apache-2.0), a build-time tool; no
Python source files ship. Bundled runtime components and their licences:

  - Microsoft Visual C++ runtime (redistributable files of the MSVC toolset)
