DWG to Excel 0.4.1

DataDrivenConstruction · Windows x64 · AutoCAD R11/R12 … 2018+ (AC1009–AC1032) · 2026-10-16

Быстрый старт

  1. Запустите DWG to Excel.exe.
  2. «Добавить файлы…» или «Добавить папку…».
  3. Выберите папку результатов и нажмите «Конвертировать».
  4. Для каждого чертежа создаётся новая папка: Excel, CSV, JSONL, DXF, SVG и отчёт.

Quick start

  1. Run DWG to Excel.exe.
  2. Use “Add files…” or “Add folder…”.
  3. Choose the result folder and press “Convert”.
  4. Each drawing gets a new folder: Excel, CSV, JSONL, DXF, SVG and a report.

Командная строка / Command line

cli\dwg2excel.exe "drawing.dwg" --output "results"
cli\dwg2excel.exe *.dwg -o results --json --no-svg

Честное покрытие

Каждая запись DWG попадает в таблицу с состоянием: DECODED, PARTIAL, REFUSED (причина сохранена), ENVELOPE_ONLY или UNIMPLEMENTED. Значения, которые не удалось прочитать надёжно, остаются пустыми — ничего не подставляется по умолчанию. Итоги — в REPORT.txt и report.json. Координаты — в системе объекта, без пересчёта единиц.

Honest coverage

Every DWG record becomes a row with its state: DECODED, PARTIAL, REFUSED (reason kept), ENVELOPE_ONLY or UNIMPLEMENTED. Values that cannot be read reliably stay empty — nothing is filled in by default. Totals are in REPORT.txt and report.json. Coordinates are in the stored entity space, no unit conversion.

Редакции

Community — все функции, без ключа, без интернета и без ограничений. Paid отличается только отсутствием рекламной страницы. Кнопка «Регистрация» активирует Paid, если сервис лицензий настроен (license-config.json); любая ошибка лицензии оставляет полную Community.

Editions

Community has every feature, needs no key or internet and has no limits. Paid only removes the advertising page. “Registration” activates Paid when the licence service is configured (license-config.json); any licence problem keeps the full Community edition.

Состав и проверка / Contents and verification

MANIFEST.json и SHA256SUMS.txt — версия, коммиты исходников и SHA-256 каждого файла. Лицензии — в licenses\. Собственный декодер DWG; без ODA/Teigha, RealDWG и LibreDWG.
